# APE Electric LLC website

Static website for APE Electric LLC. The site is made with HTML, CSS, and JavaScript and can be hosted with GitHub Pages.

## Website files

- `index.html` — home page
- `about.html` — company and electrician information
- `work.html` — project photo and video gallery
- `contact.html` — contact details
- `styles.css` and `script.js` — shared styling and behavior
- `images/work/` — optimized gallery photos, videos, and video posters

The original camera uploads are intentionally excluded. The website uses the browser-friendly copies in `images/work/` instead.

## Publish with GitHub Pages

After the files are uploaded to a GitHub repository, open the repository's **Settings → Pages** and choose **Deploy from a branch**, then select the `main` branch and `/ (root)` folder. GitHub Pages will publish the home page at the repository's Pages address.
